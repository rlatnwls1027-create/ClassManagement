# 🎲 다이스 (DICE) - 6학년 1반 학급경영 & 게이미피케이션 플랫폼

> **Dream, Incentive, Class Economy**  
> 초등학교 6학년 학급을 위한 학급경제교실과 게이미피케이션 결합 학급 운영 웹 애플리케이션입니다.  
> 학급 화폐와 1인 1역, 경험치(EXP) 성장을 통해 학생들이 주도적으로 참여하고 협동하는 학급 공동체를 만듭니다.

---

## ✨ 핵심 기능

### 🎒 1. 학생 화면 (Student View)
- **내 지갑 & 성장 경험치 (EXP)**: 현재 보유 잔액(골드) 및 레벨 진행 게이지 확인 (상점에서 소비해도 누적 경험치와 레벨은 유지)
- **오늘 할 일 (1인 1역)**: 배정된 학급 직무 확인 및 **[오늘 역할 완료 ✨]** 클릭 시 즉시 보상 획득
- **오늘의 학급 퀘스트**: 교사가 공지한 일일 미션 목록 확인
- **학급 상점 & 쿠폰함**: 자리 바꾸기권, 청소 면제권, 간식 뽑기권 등 구매 및 내 보관함에서 **[사용하기]** 처리

### 👩‍🏫 2. 선생님 화면 (Teacher View)
- **학급 KPI 총괄 대시보드**: 총 유통 화폐, 학급 평균 레벨, 오늘 1인 1역 완료율 한눈에 파악
- **25명 학생 명단 관리**: 번호, 이름, 잔액, 레벨, 역할 및 개별 **[화폐 지급/차감]** 모달
- **전체 학생 일괄 지급**: 25명 전원에게 기본 일급/특별 보너스 동시 지급
- **1인 1역 배정/관리**: 12개 직무별 학생 추가/변경 드롭다운 관리
- **학급 상점 관리**: 새로운 상품/쿠폰 등록, 재고 추가 및 삭제
- **전체 거래 로그**: 학급 내 모든 화폐 입출금 기록 열람

## 🎨 디자인 시스템 특징
- **순수 흰색 배경 (`Pure White, #FFFFFF`)**: 군더더기 없이 깨끗한 교실 화면
- **보더리스 디자인 (No-Border 원칙)**: 딱딱한 테두리를 지양하고 부드러운 소프트 블루 면 분할(`#EFF6FF`, `#F8FAFC`)과 넉넉한 패딩으로 영역 구분
- **버튼 그림자 & 엘리베이션**: 모든 버튼에 입체감 있는 부드러운 그림자(`box-shadow`)와 호버 인터랙션 적용
- **핵심 액션 오렌지 포인트**: `[화폐 지급 확정]`, `[오늘 역할 완료]`, `[구매하기]`, `[사용하기]` 등 핵심 결정 버튼에만 주황색 포인트 집중
- **단일 고딕 서체**: 프리텐다드(Pretendard) 단일 서체군으로 최고의 가독성 제공

## 🚀 빠른 시작 방법

별도의 서버 설치 없이 웹 브라우저에서 바로 열거나 로컬 웹 서버로 실행할 수 있습니다.

```bash
# 로컬 웹 서버 실행 (npx)
npx serve -p 8080

# 또는 Python 내장 웹 서버 실행
python -m http.server 8080
```

브라우저에서 `http://localhost:8080` 또는 `index.html`을 열어 사용합니다.
